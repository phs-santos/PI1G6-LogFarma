# backend

API do projeto **Localização, Reposição e Entrega de Medicamentos** (PI — Fatec Taquaritinga). Node + Fastify 5 + TypeScript.

## Requisitos

- Node 20+
- pnpm 10 (`corepack enable`)

## Rodando

```bash
pnpm install
cp .env.example .env
pnpm dev            # http://localhost:3333/api/health
```

Outros: `pnpm typecheck`, `pnpm build`, `pnpm start`.
