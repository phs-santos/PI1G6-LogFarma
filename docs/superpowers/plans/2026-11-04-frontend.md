# Telas do LogFarma — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Telas dos cinco perfis (paciente no celular; farmácia, fornecedor e gestor no computador; entregador no celular) na direção visual "Receituário e tarja", com as três cenas da Dona Maria funcionando de ponta a ponta no navegador.

**Architecture:** Componentes visuais e tokens no `packages/style-guide` (testados com Vitest + Testing Library + axe e documentados no Storybook). Telas no `apps/frontend` com React Router (rotas por perfil e guarda de perfil) e TanStack Query (dados da API e atualização periódica), acessando a API só por funções tipadas em `src/api/`. Cinco leituras novas e um ajuste de seed no backend. Playwright encena as três cenas contra o backend real com o banco `pi_e2e`.

**Tech Stack:** React 19 + Vite 8, React Router 8.5, @tanstack/react-query 5.105, @fontsource/atkinson-hyperlegible 5.3, Vitest 5 + jsdom 30 + @testing-library/react 16 + user-event 14 + jest-dom 7 + vitest-axe 0.1 (axe-core 4.14), @playwright/test 1.64 + @axe-core/playwright 4.14. Backend: Fastify 5 + Drizzle.

**Spec:** `docs/2026-11-04-frontend-design.md` (e `docs/2026-11-03-backend-design.md` para a API)

## Global Constraints

- Cores **só** pelos tokens: `--color-ink #1F3F8F`, `--color-paper #FFFFFF`, `--color-rule #D6E0F3`, `--color-text #1A1A1A`, `--color-text-muted #4A4A4A`, `--color-ok #1E7A46`, `--color-tarja-red #C8102E`, `--color-tarja-black #000000`, `--color-attention-bg #FFF4D6`. Nada de hex/px soltos fora de `tokens.css`.
- Letra **Atkinson Hyperlegible** 400/700. Celular: base 20 px, títulos 28/24, mínimo 17, altura de linha 1,5. Computador: base 16, títulos 24/20, mínimo 14.
- Contraste de texto ≥ 7:1; foco visível (anel de 3 px tinta azul com folga branca); alvos ≥ 56 px no celular, ≥ 44 px no computador; `prefers-reduced-motion` respeitado; nada só por cor; um `h1` por tela.
- Proibido: rótulos em MAIÚSCULAS, metadados com "·", setas "→" em botões, cartões cinza idênticos com sombra padrão, degradês decorativos, ícone sem texto.
- Texto em português simples, voz ativa, sem termo técnico para o paciente ("Seu pedido", "chegou", nunca "status", "dispensação", "fulfillment"). O texto do botão é a ação e a tela seguinte usa o mesmo nome.
- Linhas da receita (`--color-rule`) só como divisória entre seções, nunca atrás de texto.
- Frontend: UI só via `@fatec-pi/style-guide`; `fetch` só em `src/api/`; carregando, erro e vazio tratados em toda tela que busca dados; caminhos `/api/...` relativos.
- Atualização: `LIVE = 3000 ms` (pedido, avisos, listas da farmácia, entregador), `REGULAR = 30000 ms` nas demais; nunca quando a aba não está visível.
- TS strict, sem `any`; imports relativos com `.js` só no backend (NodeNext); frontend e style-guide usam imports sem extensão (Bundler).
- `pnpm format` antes de cada commit; commits em português, imperativo, **sem linha de coautoria**.
- Ao fim de cada tarefa: `pnpm typecheck` e o `test` do pacote tocado verdes.

## Review Focus

- **Sessão expira no meio do uso** (cookie de 8 h vence): qualquer chamada com 401 leva para **Entrar** com "Sua sessão terminou. Entre de novo." e, depois de entrar, volta para a tela onde estava. Teste em Task 5.
- **Internet falha numa tela que se atualiza sozinha:** a tela mostra o último dado e um aviso com **Tentar de novo**, nunca fica em branco. Teste em Task 7 (Seu pedido).
- **Paciente nega a localização** no cadastro: o cadastro continua sem coordenadas e o resultado mostra a unidade sem quilômetros, com o mapa pelo endereço. Testes em Task 8 e Task 6.
- **Celular estreito (360 px) e letra aumentada:** nenhuma tela do paciente ou do entregador rola para o lado. Teste em Task 15.
- **Toque duplo em botão de ação** (Confirmar pedido, Separar, Enviar, Entreguei): o botão fica desabilitado com "Enviando…" enquanto a ação não termina, e a ação vai uma vez só. Testes em Task 7 e Task 10.
